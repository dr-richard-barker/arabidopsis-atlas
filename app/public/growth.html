What's real data vs. a technique choice

Real: every stage-transition day above is a measured value from Boyes DC, Zayed AM, Ascenzi R, McCaskill AJ, Hoffman NE, Davis KR, Görlach J (2001), "Growth Stage-Based Phenotypic Analysis of Arabidopsis," The Plant Cell 13(7):1499–1510, doi:10.1105/tpc.010011 (soil-grown Col-0, 16h photoperiod, 22°C/20°C day/night). Leaf count, rosette size, and flower/silique presence in the animation are all driven directly by those real day values, not an invented curve.

Disclosed technique choices, not measurements:

  • The shape of each organ's brief emergence (scaling in over ~1.5 days) is ours — the real data is when an organ appears, not the exact speed it expands at.
  • Root growth has no Boyes-equivalent timing source (that paper covers shoot phenotypes only) — root depth here follows the rosette-growth fraction as a disclosed proxy, not an independently measured root-growth curve.
  • Fine geometric detail (leaf curvature, root branching pattern) is the same citation-grounded, illustrative geometry as the interactive atlas — see its README for what that is and isn't based on.

What this is not: no claim is made that this is the most detailed 4D Arabidopsis model ever produced. The real state of the art is genuinely fragmented across imaging-based cell-lineage reconstruction, whole-plant growth modelling, and rosette phenotyping systems, each leading on a different axis of "detail" — there isn't a single existing bar to measure this against, so none is claimed.

Single-source dependency: these day-counts rest on one primary study. TAIR's own corroborating growth-stage pages returned HTTP 403 to automated verification and were not independently checked.
